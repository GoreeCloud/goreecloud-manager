# Third-Party and Separately Licensed Material

GoreeCloud Manager is licensed under `AGPL-3.0-only`. Some dependencies and incorporated assets remain governed by their own licenses. Inclusion in GoreeCloud Manager does not replace, narrow, or terminate those independent grants.

The Linux desktop acceptance package currently bundles runtime material from PySide6 / Qt for Python, shiboken6, psutil, PyYAML, PyInstaller and CPython. The Debian build must preserve the exact license and copyright material shipped with the installed dependency distributions and the packaged Python runtime. The generated package stores that material under `/usr/share/doc/goreecloud-manager/third-party/`.

The canonical Wardveil Security mark used by Manager originates from the GoreeCloud Wardveil Security project and retains the upstream MIT grant and applicable branding requirements.

This file is an inventory aid, not a substitute for the license texts and notices supplied with each component. When dependencies change, the package-time notice collector and licensing review must be repeated.
