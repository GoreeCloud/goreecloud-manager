# GoreeCloud Manager Public Static Website

Canonical public static-site source now lives in `GoreeCloud/goreecloud-static-websites` under `sites/manager/`.

This `website/` subtree is retained only as transitional deployment/history material until Cloudflare Pages is cut over to the central repository and the exact production revision is verified. New authoritative changes to the public informational site at `manage.goreecloud.com` belong in the central static-site repository.

The authenticated private GoreeCloud Manager application, its Django runtime, integrations, operational authority, and private publication model remain authoritative in this repository and are not part of the static-site migration.
